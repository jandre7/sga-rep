# Continuidade do projeto

Comece pelo README.md. O HTML da raiz é a fonte editável da interface. Ajuste o encaminhamento da operação em servidor-local.mjs e a inicialização em Iniciar-Piloto.ps1. Preserve a memória devolvida pelo motor e o tratamento de inconsistências por item, inclusive em respostas HTTP 200.

Para retomar o trabalho, confira a revisão Git e os testes. Para mudanças tributárias, fixe a revisão e a base oficial, confira a data dos fatos e documente as premissas. Mantenha a distinção entre tributos líquidos anuais informados, cálculo por operação e desembolso efetivo. Registre as alterações técnicas no Git e as decisões de produto no cofre. Use dados fictícios em testes, exemplos e capturas.

O motor exige JDK 25 desde a 1.7.0; mantenha `-XX:-UseBASE64Intrinsics` nos scripts que iniciam a JVM. Próximas investigações: reconciliar a versão do GitHub com a distribuição online, verificar se as migrações do Regime Regular (V0068, V0071) geram o banco do Simples e avaliar com o escritório um relatório anual de premissas por cliente. Hospedagem, acesso por contabilidade, cobrança e autorização para lançamento são decisões pendentes. O projeto está em fase de piloto interno.
